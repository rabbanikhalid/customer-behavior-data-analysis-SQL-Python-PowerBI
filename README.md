# 📊 Customer Behavior Analysis Dashboard
## 📌 Overview
This project presents an end-to-end data analytics pipeline to analyze customer shopping behavior using transactional data. The goal is to uncover insights into purchasing patterns, customer segmentation, product performance, and subscription trends to support data-driven decision-making.

## 🛠️ Tech Stack
- Python (Pandas, NumPy)
- SQL (MySQL)
- Power BI (Dashboard & Visualization)
- Google Colab

## 🔄 Project Workflow
1. Data Collection  
2. Data Cleaning & Preprocessing (Python)  
3. Exploratory Data Analysis (SQL)  
4. Dashboard Development (Power BI)  
5. Insight Generation & Reporting

## 🔍 Key Insights

- Clothing generates the highest revenue and sales volume  
- Young Adults contribute the most to revenue  
- 73% of customers are non-subscribers  
- Accessories show strong secondary performance

## 🧮 SQL Analysis

Key queries were used to extract insights such as:
- Revenue by category and gender  
- Customer segmentation based on purchase behavior  
- Product performance analysis  
- Subscription impact on spending  

(See full queries in `customer_behavior_queries.sql`)
